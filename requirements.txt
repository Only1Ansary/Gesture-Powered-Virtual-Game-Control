# ============================================================
#  requirements.txt — exact pinned versions, conflict-free
#
#  Python 3.10 or 3.11 recommended (3.11 on Windows).
#  Tkinter ships with the standard CPython installer; if it
#  is missing, reinstall Python and tick "tcl/tk and IDLE"
#  in the optional features.
#
#  INSTALL ORDER:
#    1. pip install -r requirements.txt
#    2. pip install --no-deps git+https://github.com/antoinelame/GazeTracking.git
#       (GazeTracking is not on PyPI; --no-deps avoids rebuilding dlib)
#
#  KEY CONSTRAINT NOTES:
#    numpy  : must be >=1.26.0,<2.0.0
#             tensorflow==2.18.1 floor is 1.26.0
#             mediapipe==0.10.21 ceiling is <2
#             Both ultralytics and deepface are fine in this range.
#    opencv : use opencv-contrib-python ONLY — mediapipe always depends
#             on it and it conflicts with plain opencv-python (both
#             ship cv2.pyd/.so). opencv-contrib-python is a strict
#             superset so all cv2 calls in every file work unchanged.
#    protobuf: tensorflow needs >=3.20.3,<6; mediapipe needs >=4.25.3,<5
#             Intersection: 4.25.x is the only safe lane.
#    keras  : tensorflow==2.18.1 requires keras>=3.5.0; deepface
#             requires >=2.2.0 — keras==3.9.0 satisfies both.
#    dlib   : face-recognition and GazeTracking both need dlib.
#             On Windows use dlib-bin (pre-built wheel, no C++ compiler).
#             On Linux/macOS pip builds dlib from source (CMake required).
# ============================================================
